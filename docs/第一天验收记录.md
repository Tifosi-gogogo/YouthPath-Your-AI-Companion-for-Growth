## 技术与接口决定

- 用户明确要求使用 Qt，本工程按文档默认方案使用 Qt 官方 Python 绑定 PySide6。
- 本机原有 Python 3.12；已从 python.org 下载带有效 Python Software Foundation 签名的 3.11.9 安装器，安装在 `.tools/python311`，不更改系统 PATH。项目虚拟环境使用 3.11.9 x64。
- 建议 DeepSeek 为候选服务商，根地址 `https://api.deepseek.com`，模型 `deepseek-flash`。2026-10-10 核对[官方文档](https://api-docs.deepseek.com/)：POST `/chat/completions`，Bearer 鉴权，正文位于 `choices[0].message.content`；使用最小非流式请求，不预设温度、JSON 模式或 token 参数。
- 当前官方文档推荐模型已不是旧的 `deepseek-chat`。最终模型可用性、额度、延时必须通过有效账户实测后登记。
- `config/default_settings.json` 中在线地址与模型保持空值。连接工具提供候选默认值，界面只运行明确标识的开发 mock；二者不混同。
- 配色暂用浅绿/白色；A/B 正式角色与视觉尚未交付，后续替换配置和 QSS。
