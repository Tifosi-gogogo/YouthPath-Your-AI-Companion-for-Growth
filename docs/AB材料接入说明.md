# 角色和视觉材料接入说明

适用版本 0.6.0，2026-11-02。当前范围为 Qt 聊天软件，真实 API 接入按用户要求暂缓。许青原始设定、15 组对话、形象及三视图位于 `docs/materials/许青_20261012`，角色交付文档为根目录 `角色智能体.docx`。

## 角色资料

配置在 `config/character.json`。许青，昵称“小青姐”，女性，27 岁。女性设定依据已有形象与称呼补齐；音色为成年女性、中音略偏中低、温润自然的文字设计，尚无样音。软件角色介绍已同步。

| 配置字段 | 用途 |
|---|---|
| version | 素材版本 |
| name / nickname / identity | 姓名、昵称、智能体身份 |
| gender / age_description | 性别、年龄设定 |
| voice_design | 音色文字设计 |
| background / bio | 人物故事背景及小传 |
| appearance / communication_style | 外观及沟通方式 |
| traits / tagline | 性格、侧栏短文案 |
| welcome / disclaimer | 开场白、使用边界 |
| avatar / portrait | 工程内头像及立绘路径 |

头像和立绘按比例显示，配置路径不能越出资源目录。更新后检查角色介绍、欢迎语、中文和最小布局，重新打包。

## 对话和视觉

`assets/demo_cases.json` 有 6 个改编案例，首例两轮，其余一轮。仅匹配所选案例下一句，任意问题不会映射到无关回答。案例与本地安全文案仍需 A/C 审阅。提示词和上下文构造已实现，待真实接口接入后核验新问题。

样式集中在 `app/ui/style.qss`，结构在 `app/ui/main_window.py`。正式视觉更新时提供配色、字体、气泡、按钮、间距和参考图，检查 900×600、长文本及系统缩放。

## 后续交接

1. 审阅角色、案例和安全支持，不编造学校电话或专业资格。
2. 正式视觉规范到达后统一调整 QSS。
3. 用户确定调用方式后连接真实主聊天，验证上下文、网络异常和恢复。
4. 第二台 Windows 电脑验证完整发布目录。

材料中不包含 API Key，凭据只在本机配置。
