原始角色材料、形象、三视图和根目录 `角色智能体.docx` 保留；未清理本机聊天记录、接口凭据或主动导出文件。

- `compileall` 检查 app、tools 和 main.py 通过。

- PyInstaller 目录打包成功，资源包含角色图片、案例、配置及 QSS；输出目录没有拍摄启动器和近景专用图片。
