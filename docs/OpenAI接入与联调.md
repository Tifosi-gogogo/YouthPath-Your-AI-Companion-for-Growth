# OpenAI 接入与联调

日期：2026-11-13；适用软件：0.7.0。

## 先完成账户准备

1. 核对 [OpenAI API 支持地区](https://developers.openai.com/api/docs/supported-countries)。当前列表不包含中国大陆；若实际部署在中国大陆，请先确定符合服务支持范围的使用方案，或选用当地可用的兼容服务。不要将当前能使用聊天软件视为 API 可用的证明。
2. 打开 [OpenAI 开发者平台](https://platform.openai.com/)，登录自己的账户，确认有可用 API 额度及模型权限。页面中的账户、计费或验证操作需要你本人完成。
3. 在 [API Keys](https://platform.openai.com/api-keys) 页面创建项目密钥，妥善保存。不要把密钥发到聊天、文档、截图或源码中。官方说明见 [开发快速开始](https://developers.openai.com/api/docs/quickstart)。

## 填入软件

1. 启动 `dist/Qingyu/Qingyu.exe`，点击右上角“设置”。
2. 点击“填入 OpenAI 配置”，自动填写根地址 `https://api.openai.com/v1`、模型 `gpt-5.4-mini`。该模型的官方页面列出 Chat Completions 支持；实际能否调用取决于账户权限：[模型说明](https://developers.openai.com/api/docs/models/gpt-5.4-mini)。
3. 在密码框粘贴自己的 API Key。密钥只在当前软件进程内存使用；关闭软件后重新填写。地址和模型会保存在本机。
4. 点击“测试连接（一次 API 调用）”，等待成功或具体错误。此操作会调用真实 API，可能产生费用。成功后点击“保存”。
5. 在顶部点击“切换在线聊天”，输入任意新问题并发送。顶部应显示“在线聊天 · 发送至 AI 服务”。保存设置本身不会切换模式。

## 验收真实对话

使用无个人隐私的测试问题，例如“本周论文初稿和社团活动撞在一起，我每天只有两小时空余，怎么安排？”再追问两轮，例如“我最担心论文写不完”和“能给我一个明天的安排吗”。

确认：回复与问题贴合、能承接追问；正文可读；标签和建议有则展示、无则为空；本机历史重开不产生新请求；在服务商控制台核对调用记录。不要只用“测试连接成功”代替主聊天验收。

错误时按提示修正账户或设置；保存后在主窗口点击“重试”，复用原问题。不要连续重复发送。若要交流测试结果，只提供错误提示或脱敏调用信息，不提供密钥或私人聊天。

## 数据与限制

在线请求采用 [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，包含角色规则、近期完整成功对话和当前问题。仅向确切的 OpenAI 主机发送 `store=false` 和 JSON 输出模式；其他兼容接口保持通用参数。`store=false` 不是零数据保留承诺，服务商数据处理规则仍适用。

本机历史为普通 JSON 文件，不是加密保险箱。导出同样包含聊天内容。停止等待只丢弃结果，不能承诺远端停止生成或计费；连接和读取可能继续到网络超时，线程退出前无法发送下一条。默认界面等待截止 50 秒，可在请求仍结束中的状态稍候。

软件完成接线和受控回归测试，不代表已通过真实供应商、专业心理安全或第二台电脑验收。
