# API 接入与补丁验收记录

版本：0.7.0；日期：2026-11-13。

## 本轮实现

主窗口新增在线 / 离线模式切换。在线链路为输入校验、配置校验、角色提示词与最近 6 轮成功上下文、ChatWorker 后台请求、HTTP 响应校验、结果解析、主线程提交和本机保存。上下文预算为 12000 字符，不重复加入本轮问题，失败、取消、离线与安全支持消息不进入普通历史。

保存设置不会静默切换模式；切换创建新会话，恢复历史自动采用记录模式。缺少配置保留草稿、不创建失败消息；API 失败复用原用户消息重试，并使用最新配置和新请求 ID。取消 / 超时忽略迟到结果，后台结束前不启动第二个任务，关闭窗口等待线程退出。

设置新增“填入 OpenAI 配置”，默认根地址 `https://api.openai.com/v1`、模型 `gpt-5.4-mini`；不会附带密钥或自动发出测试请求。OpenAI 请求使用 JSON 输出模式和 `store=false`；其他兼容服务保持通用请求参数。

## 检查发现与补丁

| 问题 | 补丁 |
|---|---|
| 后台请求模块未连接主聊天，配置无法用于自由对话 | 接通真实在线链路及显式模式切换 |
| 服务端正文没有传输大小上限，异常服务可能造成过大内存占用 | HTTP 分块读取，解码后累计最多 1 MiB，超限关闭响应；逐块检查请求时间 |
| 深层嵌套配置 / 最近记录索引可能抛出未处理的递归异常 | 配置限制 64 KiB、索引限制 4 KiB，捕获 RecursionError 并保留原文件 |
| 模型内容解析前没有整体大小限制 | 解析前最多 65536 字符，正文仍最多 3000 字符 |
| 设置临时文件清理失败可能覆盖原始保存错误 | 捕获清理异常，保留受控提示与旧设置 |
| elevated 风险返回没有附加本地支持提示 | elevated / urgent 均附加安全卡片；明确本地危险线索缺密钥时仍展示 |
| 原界面只声明本机保存，在线后缺少传输说明 | 顶部、底部、设置和使用说明明确在线传输当前问题与近期对话 |

已有 HTTPS 校验、禁重定向、密码输入、密钥不落盘、错误正文不显示、纯文本气泡、UUID 路径校验、原子保存与迟到请求隔离继续保留。

## 验证方法

新增测试覆盖真实 worker 的后台执行、连续三轮上下文、缺密钥草稿与安全卡、错误后修改配置重试、取消后迟到回复、模式切换与历史恢复、异常响应大小及嵌套结构、损坏配置和索引。

另用本机 HTTP 服务实际接收 requests 请求，完成控制器 → worker → HTTP → 解析 → 历史的三轮闭环，验证请求路径、Bearer 头、OpenAI 参数和上下文。此测试使用虚构密钥和本机服务，不是 OpenAI 服务验证。具体自动测试数量、打包和冒烟结果见 `software_release_verification.json`。
