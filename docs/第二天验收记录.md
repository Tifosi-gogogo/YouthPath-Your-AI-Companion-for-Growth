## 数据与异常契约

- `reply` 必须是非空字符串，最多 3000 字符；超长报错，避免静默截断。
- `emotion_tags` 最多 3 个，每个最多 8 字符；`action_suggestions` 最多 3 个，每个最多 120 字符；错误项过滤、重复项去除，正文仍保留。
- 风险接受 `normal`、`elevated`、`urgent`，错误或缺失值为 `unknown` 并记录解析警告。
- 支持 JSON 代码块与纯文本降级；错误 JSON、重复键、空内容、缺失正文不直接显示到聊天气泡。
- HTTP 请求非流式，禁止重定向，无自动重试；映射鉴权失败、额度不足、无权限、地址/模型错误、限流、5xx、网络及超时。
- 设置文件仅保存根地址、模型与超时；Key 只来自内存或环境变量。保存使用同目录临时文件和原子替换；坏文件保留，写入失败保留旧设置。
- 停止等待不强杀 QThread，也不能撤回已发出的 HTTP 请求。过期结果不会提交；窗口关闭等待线程实际结束。日志不包含请求正文、回复正文或 Key。
