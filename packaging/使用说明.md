# 青语伴行 0.7.0 使用说明

单文件版双击 `Qingyu-Flash.exe` 启动，无需安装 Python，也无需附带依赖文件夹；首次解压启动可能稍慢。目录版仍需完整保留 Qingyu 文件夹及 `_internal` 依赖目录。

## 案例交流

首次启动使用离线案例，顶部持续显示“预设案例 · 非实时 AI 回复”。点击顶部“切换在线聊天”可进行真实对话；切换时保留原会话并新建独立记录。

从左侧选择故事，点击“填入示例”，再点击“发送”。默认“任务堆在一起”支持两轮，其余案例各一轮。自由问题不会生成实时回复，会提示使用预设问题。等待期间可停止，后台退出后可重试。

Ctrl + Enter 发送，Enter 换行；单条不超过 2000 字符。情绪标签不是心理诊断，行动建议仅用于成长陪伴。

## 角色与设置

角色介绍包含许青的名字、昵称、女性性别设定、27 岁年龄设定、背景、性格、形象、小传、开场白及音色设计。音色为文字方案，目前没有样音或语音合成功能。

默认接口为 DeepSeek Flash：根地址 `https://api.deepseek.com`，模型 `deepseek-flash`。点击右上角“设置 / API Key”打开添加密钥窗口，点击“使用 DeepSeek Flash”，在 API Key 输入框粘贴自己的密钥；“显示 / 隐藏”可检查输入。点击“测试连接（一次 API 调用）”，成功后点击“保存”。回主窗口点击“切换在线聊天”，输入自由问题并发送。已有本机保存的接口设置优先于默认值；也可填写其他兼容服务的 HTTPS 根地址和模型。切换服务商预设会清空输入框中的旧密钥，请填写对应服务商的密钥。

API 密钥需在所选服务商的开放平台创建，账户需具备可用额度及模型权限。密钥不包含在发布包中，也不写入配置文件；仅在本机临时填写或使用 `QINGYU_API_KEY`。关闭软件后需重新填写。不要向他人分发自己的密钥。

在线发送会将当前问题、角色提示词和最近最多 6 轮完整成功对话发给配置的服务。连接测试和在线发送可能产生费用；不会自动重试或静默切到案例。停止等待不保证远端生成或计费取消，后台结束前请稍候。OpenAI 请求使用 `store=false`，不代表服务端完全不保留数据。

## 历史与导出

记录自动保存在 `%LOCALAPPDATA%/QingyuCompanion/Qingyu`，重启恢复最近会话。新会话与切换案例保留旧记录；本机历史可按问题和回复搜索，打开不会重新请求。

导出支持 TXT / JSON，保留模式、时间、状态、正文、标签和建议。清空本会话只删除当前会话，其他历史和已导出文件保留。保存失败时先重试保存或导出，避免直接关闭造成未保存内容丢失。

## 常见情况

- 自由问题无法发送：切换在线聊天，并在设置中配置地址、模型和密钥。
- API Key 无效：重新填写密钥并保存，再点击主窗口“重试”，不必重复输入问题。
- 额度不足、429、模型不可用：在服务商平台检查额度、频率限制和模型权限；不要连续点击重试。
- 正在结束后台任务：稍候再发送或重试，避免重复。
- 历史无法读取：原文件保留，可使用新会话，不要覆盖原记录。
- 导出失败：选择可写目录；本机保存失败可点击“重试保存”。
- 本地安全提示不能替代现实专业支持或紧急服务。

本版本没有拍摄布局、录制工具或视频播放器。发布包仍需在第二台目标 Windows 电脑独立验收。

在线功能已完成 DeepSeek Flash 真实连接及主聊天三轮验证；部分回复为普通文本，此时标签和建议为空。内容安全规则提供有限保护，仍需团队人工审阅案例和真实输出。
