# 青语伴行

当前版本：**0.7.0，在线聊天与离线案例版**，2026-11-13。Python 3.11 + PySide6 6.8.3 / Qt Widgets。真实 API 主聊天已接线，支持兼容 Chat Completions 的 HTTPS 接口；OpenAI 可一键填入地址及模型。尚未使用用户密钥完成真实服务验收。

## 启动

- 双击 `dist/Qingyu/Qingyu.exe`，保留同目录的 `_internal` 依赖文件夹。
- 源码运行：`.\.venv\Scripts\python.exe main.py`。
- 软件内“新会话”可重新开始；`main.py --fresh-demo` 跳过最近会话恢复，旧记录保留。

## 已实现功能

| 功能 | 行为 |
|---|---|
| 角色介绍 | 许青、小青姐、女性、27 岁、人物背景、性格、外观、音色文字设计、开场白和边界 |
| 离线案例 | 6 个案例覆盖学业、考研就业、情感、人际和成长；首个案例支持两轮 |
| 聊天操作 | 输入、发送、等待、停止、重试、2000 字符限制、Ctrl + Enter 发送 |
| 回复展示 | 正文、情绪标签、行动建议；保留阅读位置，可跳到新回复 |
| 会话管理 | 自动保存、最近会话恢复、新会话、本机历史、全文搜索、TXT / JSON 导出、清空本会话 |
| 故障恢复 | 保存失败保留内存对话并允许重试或导出；损坏文件保留并提示；旧版案例记录兼容读取 |
| 安全支持 | 未联网也可触发本地安全提示；角色提示词、输出解析和安全兜底已实现 |
| 在线聊天 | 顶部切换模式；设置、密码框、校验、连接测试、后台真实请求、多轮上下文及重试 |

软件已移除专用拍摄布局、录制入口及脚本。原始角色素材和根目录 `角色智能体.docx` 继续保留。

## 使用方式

1. 选择左侧故事，点击“填入示例”，再点击“发送”。
2. 等待期间可停止；后台完全退出后才能重试或继续。
3. 查看正文、标签和行动建议。有下一轮时，再次填入示例即可。
4. “本机历史”可搜索问题或回复内容，打开旧会话不会重新发送请求。
5. 导出支持 TXT / JSON；清空只删除当前会话，保留其他历史和已导出文件。

离线案例仅支持下一条示例问题。自由输入请点击顶部“切换在线聊天”，在设置中填写 API 配置后发送。切换模式创建独立会话，历史不混入；打开旧记录会恢复对应模式，不自动发出请求。安全提示不依赖 API。

## 本机数据与 API

正式数据目录为 `%LOCALAPPDATA%/QingyuCompanion/Qingyu`。会话在 `sessions`，最近会话指针为 `latest_session.json`，日志在 `logs`。记录用原子写入，未完成消息恢复为失败，不自动重新请求。导出包含模式、时间、角色版本、正文、标签和建议，不包含 Key、请求头或系统提示词。

主聊天已接通后台请求、角色提示词、最近最多 6 个完整成功轮次（总上下文预算 12000 字符）及结果解析。保存接口设置不会自动切换模式；测试连接和在线发送均会调用所配置服务，可能产生费用。密钥仅在本机密码框临时填写或通过 `QINGYU_API_KEY` 提供，不写入配置文件或发布包。在线模式会传输当前问题和近期对话；本机聊天记录为普通 JSON，请妥善保管设备。

OpenAI 操作步骤与官方来源见 `docs/OpenAI接入与联调.md`。HTTP 服务端响应限制为 1 MiB，模型内容解析前限制 65536 字符，正文仍限制 3000 字符。停止等待会忽略迟到结果，不保证远端停止生成或计费；后台结束前不允许再次提交。OpenAI 请求显式使用 `store=false`，这不代表零数据保留。
